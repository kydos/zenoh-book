# zenoh-book
The Zenoh Book

## Building

Install [mdBook](https://rust-lang.github.io/mdBook/):

```bash
cargo install mdbook
```

Build the book (output written to `book/`):

```bash
mdbook build
```

Serve locally with live reload at <http://localhost:3000>:

```bash
mdbook serve --open
```
